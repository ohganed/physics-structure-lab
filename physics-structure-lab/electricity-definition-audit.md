## 各導入箇所の確認内容

### 1. 電荷とクーロンの法則

**帯電と電荷保存**（`charged-bodies`）

- 式 1：全電荷の保存 — 2物体を一つの系として囲い、電子の移動前後の正味電荷を比較する。（図 ID `charged-bodies:0`）
- 式 2：電荷の量子化 — 電子数の差が正味電荷を決めることを示す。（図 ID `charged-bodies:1`）

**二つの点電荷に働く力**（`coulomb`）

- 式 1：力の距離依存性 — 2つの電荷間距離rと、作用点での力の方向を図示する。（図 ID `coulomb:0`）
- 式 2：符号付きクーロン力ベクトル — 電荷2に働く力は電荷1との直線上を向き、符号で向きが変わる。（図 ID `coulomb:1`）

**複数の電荷による力**（`superposition`）

- 式 1：力のベクトル和 — 試験電荷から出る2本の力の矢印と合力を一つの図に示す。（図 ID `superposition:0`）
- 式 2：座標成分への分解 — 合力の水平方向と鉛直方向の成分を別々に示す。（図 ID `superposition:1`）

### 2. 電場とガウスの法則

**電場と試験電荷**（`field-definition`）

- 式 1：電場の定義 — 正の試験電荷qに働くFを描き、その同じ場所でE=F/qを対応させる。（図 ID `field-definition:0`）
- 式 2：電荷が電場から受ける力 — 同じ電場Eでもqの符号によって力の向きが逆になる。（図 ID `field-definition:1`）

**点電荷の電場と電気力線**（`field-lines`）

- 式 1：点電荷による電場 — 中心電荷Qから距離rの場所の電場を図示する。（図 ID `field-lines:0`）
- 式 2：電場の重ね合わせ — 同じ位置における2つの電場ベクトルと合成電場を描く。（図 ID `field-lines:1`）

**電束とガウスの法則**（`gauss`）

- 式 1：電束の定義 — 面の外向き法線dAと電場Eのなす角を描く。（図 ID `gauss:0`）
- 式 2：ガウスの法則 — 閉曲面内の電荷Qと、表面を外向きに貫く電場を示す。（図 ID `gauss:1`）

### 3. 電位と電位差

**電位差と電場のする仕事**（`potential-work`）

- 式 1：電位差の定義 — A点とB点の電位と電荷qの位置エネルギーを対応させる。（図 ID `potential-work:0`）
- 式 2：電場の仕事と電位差 — 電場方向の移動A→Bに対する力と変位を同時に表示する。（図 ID `potential-work:1`）

**平行板の電場と電圧**（`uniform-field`）

- 式 1：一様な場での仕事 — 平行板間の電場方向に正電荷が距離d進む状況を図示する。（図 ID `uniform-field:0`）
- 式 2：一様電場と電圧 — 極板間隔d、電位差ΔV、電場Eを同じ図に表示する。（図 ID `uniform-field:1`）

**電位の勾配と電場**（`potential-gradient`）

- 式 1：電場の線積分 — AからBへの微小変位drと電場Eの方向を示す。（図 ID `potential-gradient:0`）
- 式 2：電位の勾配 — 等電位線に直交して電位の低い方向へ電場が向くことを示す。（図 ID `potential-gradient:1`）

### 4. コンデンサーと誘電体

**平行板コンデンサーの電気容量**（`capacitance`）

- 式 1：電気容量の定義 — 極板上の+Qと−Q、および両端の電位差ΔVを同じ図に示す。（図 ID `capacitance:0`）
- 式 2：平行板の電気容量 — 極板の面積Aと距離dを区別して示す。（図 ID `capacitance:1`）

**電荷を蓄えるための仕事**（`capacitor-energy`）

- 式 1：微小充電仕事 — 現在の電荷qにおける電圧V(q)と、微小な追加電荷dqを示す。（図 ID `capacitor-energy:0`）
- 式 2：蓄積エネルギーの定義 — 電圧–電荷グラフの0からQまでの三角形面積を示す。（図 ID `capacitor-energy:1`）

**誘電体の分極と境界条件**（`dielectric`）

- 式 1：誘電率と分極 — 誘電体内の束縛電荷の偏りと、極板間の電場を示す。（図 ID `dielectric:0`）
- 式 2：電荷固定と電圧固定 — 電池から切り離す場合と接続する場合を区別する。（図 ID `dielectric:1`）

### 5. 電流・抵抗・微視的な伝導

**電流は電荷の移動率**（`current-definition`）

- 式 1：電流の定義 — 導線の断面を通る電荷ΔQと時間Δtを示す。（図 ID `current-definition:0`）
- 式 2：担体のドリフトと電流 — 断面積A、担体密度n、ドリフト速度vdを一つの状況で示す。（図 ID `current-definition:1`）

**電圧と電流と抵抗**（`ohm`）

- 式 1：オーム性抵抗の関係 — 二端子抵抗にかかる電位差と通る電流を同時に示す。（図 ID `ohm:0`）
- 式 2：抵抗率と導線の形状 — 導線の長さL、断面積Aと抵抗率ρを示す。（図 ID `ohm:1`）

**抵抗での電気エネルギー変換**（`joule`）

- 式 1：電力の定義 — 一定時間に抵抗へ入る電荷とエネルギーの移動を示す。（図 ID `joule:0`）
- 式 2：抵抗のジュール熱 — 抵抗の両端電圧と電流から内部エネルギーへ移る電力を示す。（図 ID `joule:1`）

### 6. 直流回路とキルヒホッフの法則

**直列・並列回路の電流と電圧**（`series-parallel`）

- 式 1：直列合成抵抗 — 一本の経路を同じ電流Iが順に通る二抵抗を描く。（図 ID `series-parallel:0`）
- 式 2：並列合成抵抗 — 同じ2節点に結ばれた二つの枝と枝電流を描く。（図 ID `series-parallel:1`）

**節点と閉回路での保存則**（`kirchhoff`）

- 式 1：キルヒホッフの電流則 — 分岐点を囲う境界で流入・流出の電流を示す。（図 ID `kirchhoff:0`）
- 式 2：キルヒホッフの電圧則 — 閉回路を一周した電位の上昇と下降を向き付きで示す。（図 ID `kirchhoff:1`）

**起電力と内部抵抗**（`battery`）

- 式 1：起電力と端子電圧 — 電池内部の起電力、内部抵抗の電圧降下、端子の電位差を示す。（図 ID `battery:0`）
- 式 2：負荷電流の決定 — 外部抵抗Rと内部抵抗rが同じループの電流を担う。（図 ID `battery:1`）

### 7. RC回路と時間変化

**コンデンサーが充電される速さ**（`charging`）

- 式 1：RC充電回路の電圧収支 — 電池、抵抗、コンデンサーの位置と電圧の向きを示す。（図 ID `charging:0`）
- 式 2：充電の微分方程式 — Qが増えるほど電流が減ることをグラフで示す。（図 ID `charging:1`）
- 式 3：指数関数の充電解 — 時間τ=RCの時点で最終電荷の約63.2%となることを図示する。（図 ID `charging:2`）

**コンデンサーの放電**（`discharging`）

- 式 1：RC放電の微分方程式 — 蓄えた電荷Qと放電電流がともに減少する状況を示す。（図 ID `discharging:0`）
- 式 2：指数関数の放電 — 時間τで電荷が初期値の約36.8%になることを示す。（図 ID `discharging:1`）

**RC回路のエネルギー収支**（`rc-energy`）

- 式 1：電池から供給された仕事 — 一定電圧ℰの電池から移動する電荷の総量を示す。（図 ID `rc-energy:0`）
- 式 2：充電エネルギーの収支 — 電源からの仕事を、コンデンサーの蓄積と抵抗の熱に分ける。（図 ID `rc-energy:1`）

### 8. 磁場とローレンツ力

**動く電荷が受ける磁気力**（`magnetic-force`）

- 式 1：ローレンツ力の定義 — 速度v、磁場B、正電荷に働く力Fの三方向を示す。（図 ID `magnetic-force:0`）
- 式 2：外積の大きさと角度 — vとBの角度θが0なら力が消え、90°で最大になる。（図 ID `magnetic-force:1`）

**磁場中の円運動と質量分析**（`circular-magnetic`）

- 式 1：磁気力による向心力 — 粒子の接線速度と円の中心へ向かう磁気力を同時に示す。（図 ID `circular-magnetic:0`）
- 式 2：軌道半径と周期 — 半径rと一周の時間Tを粒子の円軌道に対応させる。（図 ID `circular-magnetic:1`）

**電流が磁場を作る**（`wire-magnetic`）

- 式 1：直線電流の磁場 — 導線を囲む同心円の磁場と導線からの距離rを示す。（図 ID `wire-magnetic:0`）
- 式 2：アンペールの周回積分 — 磁場の接線方向と周回する閉路の向きを示す。（図 ID `wire-magnetic:1`）

### 9. 電磁誘導とインダクタンス

**磁束が変わると起電力が生じる**（`faraday`）

- 式 1：磁束の定義 — コイルを貫く磁束密度Bと面積の法線ベクトルを示す。（図 ID `faraday:0`）
- 式 2：電磁誘導の起電力 — 磁束の増減とコイルの起電力との対応を図示する。（図 ID `faraday:1`）

**レンツの法則とエネルギー保存**（`lenz`）

**コイルと磁場に蓄えるエネルギー**（`inductor`）

### 10. 交流・RLC回路・共振

**交流の電圧と実効値**（`ac-wave`）

**コイルとコンデンサーの位相**（`reactance`）

### 11. マクスウェル方程式と電磁波

**変位電流と電磁場の整合**（`ampere-maxwell`）

- 式 1：変位電流を含む周回則 — 充電するコンデンサーの導線電流と極板間の電束変化を対応させる。（図 ID `ampere-maxwell:0`）
- 式 2：アンペール–マクスウェル方程式の局所形 — 導電電流密度Jと変化する電場が磁場の回転を生むことを示す。（図 ID `ampere-maxwell:1`）

**電場と磁場が伝わる波**（`wave`）

- 式 1：電磁場の波動方程式 — 伝播方向に沿う電場の変化を位置と時間に対応させる。（図 ID `wave:0`）
- 式 2：光速と電場・磁場の振幅 — E、B、伝播方向の直交関係と振幅比E₀/B₀を示す。（図 ID `wave:1`）

**電磁波のエネルギーと流れ**（`energy-flux`）

- 式 1：電磁場のエネルギー密度 — 電場と磁場のエネルギーを空間の同じ領域に蓄えられる量として示す。（図 ID `energy-flux:0`）
- 式 2：ポインティングベクトルの定義 — 電場Eと磁場Bの外積がエネルギーの流れる向きになる。（図 ID `energy-flux:1`）

## 図の物理的な点検と修正

- クーロン力：正負電荷が引き合う例で、力の矢印を各電荷の中心から描くよう修正
- ガウスの法則：電場の矢印が閉じたガウス面を実際に横切る位置へ修正
- 直流・RC・RLC回路：抵抗やコンデンサーを導線で短絡する誤図を排除し、素子を電気的な接続点で結ぶ
- 直列・並列：上枝と下枝が同じ2節点に接続され、抵抗素子の内部を導線が貫かないよう修正
- 磁場中の円運動：荷電粒子を円軌道上に配置し、接線速度と中心向きのローレンツ力を整合
- 電位勾配：横軸を時刻ではなく位置として描く
- コンデンサーの蓄積エネルギー：横軸を電荷qとするV–q図の下の面積を表示
- 電磁波：EとBを同一平面の同方向振動として描かず、紙面に垂直なBを記号で区別
- 電場の定義：正負の試験電荷で力の向きが逆になることを比較
- 磁気力の大きさ：vとBが平行なら力0、垂直なら最大という条件を区別
- RC過渡現象：時間定数τのグラフ上の点と63.2%・36.8%の関係を対応
- 数式修正：電気的仕事の微分 `V\\,dQ` と、RC回路の電源仕事の積分 `\\mathcal E\\,dQ` のLaTeX表記を修正
